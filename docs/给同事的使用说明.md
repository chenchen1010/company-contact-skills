# 通过共享服务查找公司联系人

把公司名单或调研报告交给助手，得到按联系优先级整理的姓名、岗位和邮箱，直接补回Excel。每家公司最多5个邮箱，数量不足会说明原因。你无需准备顶易账号，由管理员统一维护查询服务。

1. 把 `topyi-remote-search` 文件夹复制到自己的 skills 目录，例如 Codex 的 `~/.codex/skills/`，重新打开会话。
2. 准备 Node.js 22+，无需 npm 安装。
3. 向管理员领取分配给你自己的访问凭证文件，将它放在工作项目的私有位置并加入 git 忽略。不要把它放入公共分享包或发给其他人。
4. 附上调研报告，使用本包的“调研报告补充联系方式_提示词.md”。告诉助手凭证文件路径即可，避免把值粘贴到聊天。

服务地址：https://topyi.movingcostcheck.com 。这是供 skill 使用的查询接口，不是网页查询表单。管理员可以独立停用某人的访问权限。

默认先用顶易，每家公司已有5个主体匹配、非重复、未被判不可用的商务邮箱时，不再新启动Apify；不足时可用包内 `apify-linkedin-contacts` 补充。Apify需使用你自己的凭证和明确预算，目前共享服务仅覆盖顶易。

查询会排队，相同使用者的相同结果默认复用6小时，结果标注原查询时间。网络中断后继续已有任务，不重复创建。额度以服务 status 返回为准，按UTC自然日计算；一个公司挖掘任务可能访问顶易多条接口。

每家公司最多5个邮箱放同一列，姓名、岗位、优先级、核对说明及来源编号对应。数量不足如实说明，不编造邮箱。找到邮箱不代表成功收件；不会自动发开发信或测试邮件。

出现“顶易账号暂不可查询”时联系管理员恢复，无需自己登录顶易。发现、人员任职和邮箱收件判断是不同证据；来源应写“顶易采集，经共享查询服务获取”，并保留任务编号、日期和官网/人员主页的核对链接。

| 说明中出现的词 | 你需要做什么 | 带来的作用 |
| --- | --- | --- |
| 访问凭证 | 领取并保管自己的私有文件 | 无需登录顶易，也能查询；可单独停用 |
| 任务编号 | 保留助手生成的查询文件 | 网络断开后可以接着取结果 |
| 复用结果 | 查看原查询时间 | 减少重复查询和等待 |
