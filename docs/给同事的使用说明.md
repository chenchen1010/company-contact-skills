# 通过共享服务查找公司联系人

向助手说明想查询的公司、交易或联系人资料即可，提交方式和结果形式由你决定。你无需准备顶易账号，由管理员统一维护查询服务。

1. 把 `topyi-remote-search` 文件夹复制到自己的 skills 目录，例如 Codex 的 `~/.codex/skills/`，重新打开会话。
2. 准备 Node.js 22+，无需 npm 安装。
3. 向管理员领取分配给你自己的访问凭证文件，将它放在工作项目的私有位置并加入 git 忽略。不要把它放入公共分享包或发给其他人。
4. 告诉助手查询目标和凭证文件路径，避免把凭证值粘贴到聊天。只有本次需要Excel补表时，才使用包内的“调研报告补充联系方式_提示词.md”作为可选模板。

服务地址：https://topyi.movingcostcheck.com 。这是供 skill 使用的查询接口，不是网页查询表单。管理员可以独立停用某人的访问权限。

两个skill可独立使用，采集渠道和顺序按本次任务安排。Apify需使用你自己的凭证和明确预算，目前共享服务仅覆盖顶易。

查询会排队，相同使用者的相同结果默认复用6小时，结果标注原查询时间。网络中断后继续已有任务，不重复创建。共享服务不设每日或累计查询数量额度，只控制频率：每个凭证每分钟最多提交6个新任务，所有人统一排队、一次执行一个采集任务，上游请求之间至少间隔1秒。一个公司挖掘任务可能访问顶易多条接口；status 中 usedToday 只是统计，不表示剩余额度。

联系人数量、目标岗位、排序和输出格式由本次任务指定。“每家公司5个邮箱放同一列”是补表提示词的示例要求，不是skill限制。返回不足时如实说明，不编造邮箱；找到邮箱不代表成功收件，也不会自动发开发信或测试邮件。

出现“顶易账号暂不可查询”时联系管理员恢复，无需自己登录顶易。发现、人员任职和邮箱收件判断是不同证据；来源应写“顶易采集，经共享查询服务获取”，并保留任务编号、日期和官网/人员主页的核对链接。

| 说明中出现的词 | 你需要做什么 | 带来的作用 |
| --- | --- | --- |
| 访问凭证 | 领取并保管自己的私有文件 | 无需登录顶易，也能查询；可单独停用 |
| 任务编号 | 保留助手生成的查询文件 | 网络断开后可以接着取结果 |
| 复用结果 | 查看原查询时间 | 减少重复查询和等待 |
